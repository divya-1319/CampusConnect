
# CampusConnect - College Event Management System

## About the Project
CampusConnect is a web-based college event management
system developed using Python, Flask, HTML, CSS and SQLite.

It helps students explore college events and register
for available activities. Admins can manage events
through a secure login dashboard.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- SQLite
- Google Colab

## Features
- Homepage and event exploration
- Student registration
- Admin login
- Admin dashboard
- Add new events
- Edit existing events
- Delete events with confirmation
- Input validation
- Database management

## Database
SQLite is used to store:
- Student details
- Event details
- Registration details

## Installation and Execution

1. Open Google Colab.
2. Open the CampusConnect project notebook.
3. Mount Google Drive.
4. Run the project setup and Flask application cells.
5. Start the Flask server.
6. Open the generated website link.
7. Use the admin login to access the dashboard.

Note: Keep database files and admin credentials secure.
